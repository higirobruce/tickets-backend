   1. API for Deposit/Withdraw
* This API document describes in detail how the Lumicash system and the Partner’s system communicate with each other.
* API bulletins are built and publicly provided by the Lumicash system for the Partner’s system to connect.
* The partner system will connect to the wallet system through these APIs to process the following transactions: Deposit; Get account information…
